# Shopify Theme Starter for Petora

Use this folder as a ZIP upload to Shopify:

1. Zip the `shopify-theme` folder contents (not the parent folder)
2. In Shopify Admin, go to Online Store > Themes
3. Click Add theme > Upload zip file
4. Publish the theme
5. Edit products, collections, and homepage content from the Shopify theme editor

This theme is a starter matching the Petora soft white/grey brand for dog and cat beds.
